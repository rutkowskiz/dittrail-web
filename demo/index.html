DitTrail Beta

DitTrail v0.13 Beta brings Morse learning, Practice and simulated QSOs to Windows and macOS. It is still a beta, so bugs and rough edges are possible.

WHAT'S IN v0.13 Learn · Practice · SimQSO · Stats · Home

Learn now covers all 41 supported CW characters. Practice, SimQSO with live radio operation and QSO logging, Stats, profiles, settings, Coach and the built-in Operator Guide are all available.

CURRENT VERSION v0.13 Beta
01

Requirements

Windows 10 or Windows 11 (x64).

macOS · Apple Silicon or Intel (tested on macOS 15).

Full HD (1920 × 1080) is recommended. Smaller resolutions may scale incorrectly in this early build — no promises there yet. 🙂

02

Installation

Windows: Download the EXE and run it directly. No ZIP or installer is needed.

macOS: Open the DMG for your Mac, drag DitTrail.app to Applications and launch it there.

Windows security: The EXE is not Authenticode-signed. Windows or your browser may warn about an unknown publisher; check the source and SHA-256 before running it.

03

Quick start

  • On first launch, create your operator profile and let First Run guide you through the basic setup.
  • For the best experience, use a real straight key or paddles. Keyboard keying is also available with [ and ].
  • If you get lost, open the built-in Operator Guide for an overview of the current features and controls.

About this beta

v0.13 is an early beta, not a final release. It is ready to be used as a complete application, but bugs may still occur and parts of the interface or behaviour may change. Feedback is very welcome.
