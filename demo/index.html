Requirements

Windows 10 or Windows 11 is required.

Full HD (1920 × 1080) is recommended. Smaller resolutions may scale incorrectly in this early build — no promises there yet. 🙂

02

Installation

  1. Download DitTrailPublish.zip.
  2. Extract the entire ZIP archive to any folder on your PC.
  3. Open that folder and run the included .exe file.
03

Quick start

No physical key is required. You can use the [ and ] keys as the two paddle inputs.

On the right side of the screen, use the ? button to show or hide the built-in Morse alphabet cheat sheet.

Press a character key on your keyboard to hear its CW audio cue — a quick sound hint for the selected Morse character.

One last thing

This is not an official DitTrail release yet. It is simply a convenient way to share the current build, gather feedback and let a few curious operators see where the project is heading.
