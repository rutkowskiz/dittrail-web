DitTrail Beta

DitTrail v0.11 is the first fully functional beta: the core learning, practice and simulated QSO experience is now available end to end. It is still a very early beta, so bugs and rough edges are possible.

WHAT'S IN v0.11 Learn · Practice · SimQSO · Stats · Home

Learn now covers all 41 supported CW characters. Practice, SimQSO with live radio operation and QSO logging, Stats, profiles, settings, Coach and the built-in Operator Guide are all available.

01

Requirements

Windows 10 or Windows 11 is required.

Full HD (1920 × 1080) is recommended. Smaller resolutions may scale incorrectly in this early build — no promises there yet. 🙂

02

Installation

  1. Download DitTrailPublish.zip.
  2. Extract the entire ZIP archive to any folder on your PC.
  3. Open that folder and run the included .exe file.
03

Quick start

  • On first launch, create your operator profile and let First Run guide you through the basic setup.
  • For the best experience, use a real straight key or paddles. Keyboard keying is also available with [ and ].
  • If you get lost, open the built-in Operator Guide for an overview of the current features and controls.

About this beta

v0.11 is an early beta, not a final release. It is ready to be used as a complete application, but bugs may still occur and parts of the interface or behaviour may change. Feedback is very welcome.
