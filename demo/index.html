CURRENT VERSION v0.13 Beta
01

Requirements

Windows 10 or Windows 11 (x64).

macOS · Apple Silicon or Intel (tested on macOS 15).

Full HD (1920 × 1080) is recommended. On smaller displays, some interface elements may scale less effectively.

02

Installation

Windows: Download the EXE and run it directly. No ZIP or installer is needed.

macOS: Open the DMG for your Mac, drag DitTrail.app to Applications and launch it there.

Windows download: The EXE is currently distributed without an Authenticode signature. Windows or your browser may show an unknown-publisher warning. Verify the download source and SHA-256 checksum before running the file.

03

Quick start

  • Create your operator profile at first launch. First Run will guide you through the initial setup.
  • Connect a straight key or paddles for hands-on sending practice. Keyboard input is also available using [ and ].
  • Use the built-in Operator Guide to explore the available features and controls.
